# Oceanview Plumbing site (remake)

Static Astro site for the Lake Forest shop. Built to fix on-page architecture from the SEO audit: one H1 per page, dedicated service and city URLs, consistent NAP, working sitemap, no heading spam.

```bash
npm install
npm run dev
```

Then open http://localhost:4321/

```bash
npm run build
```

Set `licenseNumber` in `src/data/site.ts` when the live CSLB number is confirmed. Do not invent one.

This remake does not replace Google Business Profile work, Search Console verification, or a spam-link disavow.
